JQQ 1m Backup

JQQ 1m Backup is a personal-use tool for backing up Japanese equity market-data archives from a privately operated server to the account owner's Google Drive.

With the owner's authorization, rclone uses the Google Drive API to upload archived data and its integrity metadata, check previously stored archives, and download files for verification or recovery. It is not a public service and has no advertising functionality.
